# Приложение для онлайн-бронирования столиков в ресторане
## 1 Общие сведения
## 1.1 Основание для выполнения работ
Программа развития сетей ресторанов.
## 1.2 Заказчик работ
Заказчик: Семейный ресторан "Маруся"
## 1.3 Цель выполнения работ
Работы по настоящему Договору выполняются с целью пилотного запуска веб-приложения с услугой онлайн-бронирования столов в ресторане.
## 1.4 Состав работ
По настоящему Договору Исполнитель выполняет перечисленные ниже работы:
1) Разработка мобильного приложения для клиентов;
2) Разработка веб-панели для администраторов ресторанов;
3) Разработка API-сервиса для управления бронированиями;
4) Интеграция со шлюзом отправки SMS и push-уведомлений;
5) Разработка технической документации;
## 1.5 Сроки выполнения работ
Не более 90 дней с даты подписания договора
## 1.6 Место выполнения работ
Работы выполняются на территории Российской Федерации.
## 2 Назначение приложения для онлайн-бронирования столиков в ресторане
Приложение для онлайн-бронирования столиков должно представлять собой единый ресурс для удаленного резервирования мест в ресторанах сети. На базе сайта семейного ресторана "Маруся" будет предоставлять клиентам услугу бронирования столиков. Пользователь услуги должен иметь доступ к информации о ресторане, свободных столиках, возможность бронирования, просмотра истории заказов, управления бронированиями и получением уведомлений посредством веб-приложения и веб-интерфейса для администраторов. 
## 3 Описание услуги «Онлайн-бронирование столиков»
## 3.1 Схема предоставления услуги
Клиент через веб-интерфейс (браузер на ПК или мобильном устройстве) получает доступ к сервису бронирования. На главной странице отображается информация о ресторане, его адрес, часы работы, схемы залов и доступные временные слоты.
Клиент выбирает дату, время и количество гостей, после чего отправляет заявку на бронирование. Заявка поступает в административную панель ресторана, где менеджер подтверждает или отклоняет её. В случае подтверждения клиент получает уведомление по SMS и/или электронной почте.
Клиент имеет возможность просматривать историю своих бронирований, отменять или переносить их, а также оставлять отзывы после посещения.
## 3.2 Архитектура системы
Система состоит из следующих компонентов:
1. веб-интерфейс клиента (адаптивный, доступен с любых устройств);
2. веб-интерфейс администратора ресторана;
3. серверная часть (API-сервис, база данных);
4. интеграционный модуль с CRM-системой Заказчика;
5. интеграционный модуль со шлюзами отправки SMS и email.
Все компоненты должны быть развернуты на инфраструктуре Заказчика и обеспечивать горизонтальное масштабирование при росте количества пользователей.
