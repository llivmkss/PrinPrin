# Лабораторная работа 3

Консольное приложение на ванильном Python, данные хранятся в памяти.

## Запуск

```
uv sync
uv run python -m src.main
```

Вход администратора: логин `admin`, пароль `admin123`.

## Отступления от SOLID

- `AuthService` зависит от конкретного `PasswordHasher`: алгоритм хеширования один, отдельная абстракция избыточна.
- `BookingService` объединяет поиск, создание и отмену броней: это один агрегат с общими правилами пересечения интервалов.
- `Console` перехватывает `Exception`: по ТЗ (п. 4.2.4) пользователь не должен видеть технические ошибки.
